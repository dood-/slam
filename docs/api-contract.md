# Shared implementation contract

Specification: `.scratch/video-trajectory/spec.md`. All JSON keys use camelCase. API base `/api`.

- POST /videos multipart `file`: `{id,name,width,height,durationSec,frameCount,codec,sha256,sizeBytes,previewUrl}` (Video). GET /videos/{id} same. `sizeBytes` is the uploaded file size in bytes; older stored metadata may omit it and is normalized on read. GET /videos/{id}/preview supports HTTP Range.
- GET /engines -> `[{id:'colmap'|'cuvslam',label,available:boolean,reason:string|null}]`. Availability indicates an installed worker interpreter, not a GPU initialization check.
- POST /runs JSON `{videoId,engine?:'colmap'|'cuvslam',settings?:{sampleHz?:5,maxImageSize?:640,maxFeatures?:1500,threads?:2,overlap?:5,focalRatio?:0.8}}` -> RunStatus, 202. Default engine is COLMAP. cuVSLAM uses only `maxImageSize` and `focalRatio` (finite, 0.1–5); its panel defaults to 960 px and all frames. COLMAP ignores/drops `focalRatio`. Request snapshots and results retain only effective settings. 409 `{error:{code:'processing_busy',message:string}}` when occupied; 503 `engine_unavailable` if the cuVSLAM interpreter is absent. Runtime CUDA failures become `cuvslam_failed`; there is no fallback.
- GET /status -> RunStatus: `{state:'idle'|'running'|'succeeded'|'partial'|'failed'|'cancelled',runId:string|null,videoId:string|null,stage:string,engine?:'colmap'|'cuvslam',processed?:number,total?:number,error?:{code,message}|null}`.
- POST /runs/{id}/cancel -> RunStatus, idempotent for same completed/cancelled run; cannot cancel a different running run.
- GET /results -> array ResultSummary `{runId,videoId,videoName,engine:string,createdAt,state:'succeeded'|'partial',registeredFrames,sampledFrames}`.
- GET /results/{id} -> Trajectory. GET /results/{id}/export?format=json|csv -> download.
- GET /health -> `{status:'ok'}`. All failures use `{error:{code,message}}`.

Trajectory: `{schemaVersion:1,runId,videoId,video:Video,createdAt,engine:string,units:'arbitrary',scaleSource:null,poseConvention:'camera-to-world',settings,primaryModelId:string,models:Model[],warnings:string[]}`.
Model: `{id:string,camera:{model,width,height,params:number[]},samples:Sample[],segments:{id:string,startTimeSec,endTimeSec}[],quality:{registeredFrames,sampledFrames,coverage:number,points3D:number,meanReprojectionErrorPx:number|null,maxGapSec:number}}`.
Sample: `{frameId:number,timeSec:number,segmentId:string|null,status:'estimated'|'missing',position:[number,number,number]|null,orientationXyzw:[number,number,number,number]|null}`. Every selected frame included in each model; missing entries break lines. Estimated positions translated to first camera origin, rotations retain the engine world axes. A cuVSLAM camera has an identity rig transform, so world-from-rig is camera-to-world. Segment IDs change after missing frames. Model coordinates independent. Times relative to first decoded source PTS. Settings contain the effective engine parameters. cuVSLAM uses all decoded frames, restarts a tracker after loss into an independent model, exports no 3D points (`points3D:0`) or reprojection error (`null`), and writes the manifest last. A single-pose fragment is not a reconstructed model.

Files saved atomically; final manifest written last. Current status in API memory; completed results listed from manifests. Service host 127.0.0.1, one worker. Default storage `storage/` (SLAM_STORAGE override). Root project videos not committed. Backend package `slam` under backend/, run `uv run --project backend uvicorn slam.api:app --host 127.0.0.1 --port 8000` (verify packaging). Tests may inject a controlled process runner at external CV boundary; production must always run real reconstruction.
